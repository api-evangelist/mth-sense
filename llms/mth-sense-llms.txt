# mth Sense (RevSense)

> Mth Sense Inc., operating as RevSense, is a San Francisco mobile ad-technology company
> founded in 2011 by Mandar Agte and Mohan Balachandran and backed by Y Combinator (Summer
> 2012). It began as a mobile on-device profiling and ad-serving platform and became a
> programmatic yield and revenue-optimization platform for digital publishers: machine-learning
> yield optimization, automated ad-tag management, header bidding, and a unified reporting layer
> that aggregates ad-server and demand-partner data.

**There is no public API.** As of 2026-08-12 mth Sense publishes no developer portal, no API
documentation, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no CLI, no webhooks, and no
`/.well-known/` discovery documents. Its whole web presence is a five-page static marketing site
last dated 2017; `api.`, `docs.`, `developer.`, `app.`, `portal.` and `dashboard.` subdomains do
not resolve. RevSense is an API *consumer*, not an API *producer*: its FAQ describes using "APIs
or programmatic hooks" to configure a publisher's Google Ad Manager (DFP) ad server and SSPs such
as OpenX and PubMatic on the publisher's behalf, using credentials the publisher hands over. It
does not expose those capabilities as an interface anyone else can call.
